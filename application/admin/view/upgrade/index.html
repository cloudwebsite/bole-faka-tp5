🔐 Token 获取示例（可选，用于 Star / 提高额度）

拿到令牌后点「填写 Token」粘贴保存即可；仓库地址等已在 data/git_update.php 配好，不必改文件、不必复制配置。

🐙 GitHub
  1. 打开 github.com/settings/tokens
  2. 生成 Classic Token（或 Fine-grained）
  3. Classic 建议勾选 public_repo（公开库读写 / Star 常用）；仅只读可不勾额外权限
  4. 回到本页点「填写 Token」，粘贴后保存
🪶 Gitee
  1. 打开 gitee.com/profile/personal_access_tokens
  2. 新建私人令牌，勾选与仓库、用户相关的权限（含 Star 所需项）
  3. 回到本页点「填写 Token」，粘贴后保存

示例配置里 auto_star / star_all_mirrors 已为 true： 检查或完成更新会尝试给双源仓库点 Star；失败不影响升级本身。
